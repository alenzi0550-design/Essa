ARTIFY AI — prototype
=====================

الملفات:
- index.html: واجهة عربية متجاوبة لرفع الصورة واختيار أسلوب فني ومعاينة النتيجة.

طريقة التجربة:
1. افتح index.html في متصفح حديث.
2. ارفع صورة JPG أو PNG أو WEBP.
3. اختر الأسلوب والمقاس.

مهم:
هذه نسخة واجهة أولية وليست تحويل ذكاء اصطناعي فعلياً بعد.
زر التحويل يوضح أن محرك الذكاء الاصطناعي يحتاج إلى ربط.

الخطوة التالية لتفعيل التحويل:
- اختيار مزود توليد/تعديل الصور (مثلاً OpenAI أو Gemini أو مزود متخصص).
- إنشاء خادم backend يستقبل الصورة والاختيارات.
- حفظ مفتاح API في متغير بيئة على الخادم، وليس في المتصفح.
- إرسال الصورة إلى خدمة تعديل الصور وإرجاع الصورة الناتجة إلى الواجهة.
- إضافة سياسة خصوصية وموافقة العميل قبل رفع صوره إلى مزود خارجي.
